## 📚 About This Project

This project provides a **specification-driven engineering guide** to building autonomous humanoid robots. It bridges the gap between **classical control theory** (ROS 2, physics simulation) and **modern foundation models** (VLA, LLMs) to create robots that can truly perceive, reason, and act.

### 🎯 Core Learning Modules

| Module | Topic | Description |
|:------:|-------|-------------|
| ⚡ **Module 1** | ROS 2 Foundations | Master the industry-standard robotics framework |
| 🎮 **Module 2** | Digital Twin Simulation | Create photorealistic environments with Gazebo |
| 🧪 **Module 3** | NVIDIA Isaac | GPU-accelerated simulation & synthetic data |
| 🧠 **Module 4** | VLA Models | Vision-Language-Action for semantic understanding |
| 🚀 **Module 5** | Capstone | Full system integration & Sim-to-Real transfer |

## 🚀 Quick Start

### Prerequisites

- Node.js >= 18.0
- npm or yarn

### Installation

```bash
# Clone the repository
git clone https://github.com/sumair-khan21/Physical-AI-Humanoid-Robotics.git

# Navigate to project directory
cd Physical-AI-Humanoid-Robotics

# Install dependencies
npm install

# Start development server
npm start
```

The site will be available at `http://localhost:3000`

### Building for Production

```bash
npm run build
```

## 📖 Textbook Topics

### Module 1: ROS 2 Foundations
- ROS 2 Architecture & Communication Patterns
- Node Lifecycle Management
- DDS & QoS Tuning
- URDF Modeling for Humanoids

### Module 2: Digital Twin Simulation
- Gazebo Classic vs Ignition
- Physics Engines (Bullet, DART)
- Sensor Simulation

### Module 3: NVIDIA Isaac
- Isaac Sim Overview
- USD Open Standards
- Synthetic Data Generation
- Domain Randomization

### Module 4: Vision-Language-Action (VLA)
- Foundation Models for Robotics
- Zero-Shot Task Planning
- Multimodal Transformers

### Module 5: Capstone
- System Architecture Design
- Sim-to-Real Transfer
- Complete Demo Implementation

# Internship Portfolio - Junaid Ul Haque Sheikh

Complete single-page portfolio website showcasing 28+ live projects for software house internship applications.

## 🌟 Features
- Single-page design with smooth navigation
- 28 live projects displayed with filtering & search
- WhatsApp integration with 6 contact numbers
- Professional internship application form
- Responsive design for all devices
- Backend server for application handling
- Project statistics and analytics
